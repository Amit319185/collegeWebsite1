# Jaipur Engineering College Website

A four-page static mini-project built with HTML and a small amount of internal CSS for basic colours, spacing and readability.

## Pages
- `index.html` — Home
- `about.html` — About the college
- `courses.html` — Example engineering study areas in an HTML table
- `contact.html` — Contact section and admission enquiry form

## How to open
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click it to open it in a browser.

## Notes
- This is a student project, not an official college website.
- Verify the actual courses, address, phone number and official email before submission.
- The contact form is a front-end demo and does not send or store submissions.
- The banner images are placeholders and need an internet connection. Replace them with images you are allowed to use.
